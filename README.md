# Sowo

**Sowo dey sell while you sleep.**

An AI sales assistant for Nigerian vendors who sell on WhatsApp, built for OSCA OPEN//BUILD 2026. The full README is coming as the project takes shape.

## Quick start

```bash
corepack enable
pnpm install
pnpm dev
```

Then open http://localhost:3000.
